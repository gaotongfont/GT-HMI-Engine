# utils

通用工具集，提供数据结构和功能组件。

## 文件说明

| 文件 | 说明 |
|------|------|
| `gt_img_cache.c/h` | 图片缓存：LRU 缓存解码结果，避免重复解码 |
| `gt_queue.c/h` | 队列（FIFO） |
| `gt_fifo.c/h` | 字节流 FIFO，用于串口数据缓冲 |
| `gt_stack.c/h` | 栈结构 |
| `gt_vector.c/h` | 动态数组 |
| `gt_circular_array.c/h` | 环形数组 |
| `gt_roll_anim.c/h` | 滚动动画辅助 |
| `gt_serial.c/h` | 串口通信基础层 |
| `gt_bin_convert.c/h` | 二进制数据转换工具 |
